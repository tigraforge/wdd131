PROJECT OVERVIEW

CampusNest Site Plan

CampusNest is a student information hub designed to help university students find academic resources, organize class information, keep up with campus updates, and connect with fellow students.

1. Website Name

CampusNest

The name combines “campus,” representing university life, with “nest,” representing a welcoming place to find useful information. CampusNest aims to be a convenient online home for student resources.

Suggested tagline: Your university information hub.

2. Website Purpose

The website will organize useful student information in one place. Visitors will be able to explore academic resources, review class information, discover campus updates, and find student community information. A search feature will help visitors locate relevant sections quickly.

3. Target Audience

  • University students looking for study materials and revision support.
  • Students who want to organize class and course information.
  • Students interested in campus announcements and activities.
  • New students looking for helpful university information.

4. Site Goals

  • Make student information easy to find.
  • Provide a simple and responsive browsing experience.
  • Help students discover academic and campus resources.
  • Demonstrate practical HTML, CSS, and JavaScript skills.

5. Planned Website Pages

Home

Introduces CampusNest and provides search and links to key sections.

Resources

Organizes study materials, class information, and campus updates.

Community

Introduces student connection ideas and includes a suggestion form.

References

Lists external resources used in developing the website.

6. Color Scheme

The colors are chosen to create a clear, calm, and modern student experience.

White #FFFFFF

Cards and content areas

Soft white #F8FAFC

Page background

7. Typography

Poppins — Headings

Used for page titles, section headings, and card titles.

Inter — Body text

Used for paragraphs, navigation links, descriptions, and forms.

Planned mobile layout:

Welcome and search
Academic resources

9. Functionality

  • Responsive navigation for smaller screens.
  • JavaScript-powered search for website sections.
  • Interactive page elements and a student suggestion form.
  • Local browser storage for selected preferences or demo submissions.

Local storage features are demonstrations on the visitor's own browser; they do not send information to a server.

10. Navigation

All main pages will share a consistent navigation menu and footer. Visitors can use the links to move between the home, resources, community, and references pages.
